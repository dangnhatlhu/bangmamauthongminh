Hệ Thống Bảng Mã Màu CSS (:root)

Được cấu hình tối ưu độ tương phản (WCAG AA/AAA) và phân cấp thị giác

1. Bảng màu định nghĩa

Primary
#2563EB
Secondary
#0D9488
Text Primary
#111827
Text Secondary
#4B5563
Text Muted
#9CA3AF

2. Minh họa giao diện thực tế

Cập nhật 5 phút trước • var(--text-muted)

Thiết kế UI chuyên nghiệp với CSS Variables • var(--text-primary)

Đoạn văn này minh họa cách sử dụng var(--text-secondary) cho nội dung chính. Độ tương phản vừa phải giúp người dùng đọc văn bản dài không bị mỏi mắt nhưng vẫn duy trì độ rõ ràng cao trên mọi màn hình.

3. Đoạn mã CSS Variables tại :root

:root {
  /* 2 Màu chủ đạo (Brand & Actions) */
  --color-primary: #2563eb;       /* Xanh dương hiện đại */
  --color-secondary: #0d9488;     /* Xanh Teal điểm nhấn */

  /* 3 Mức màu xám cho văn bản (Typography) */
  --text-primary: #111827;        /* Tiêu đề & nội dung quan trọng */
  --text-secondary: #4b5563;      /* Nội dung chính / đoạn văn */
  --text-muted: #9ca3af;          /* Chú thích, phụ lục, disabled */
}
